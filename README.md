## 🎯 Назначение

Система разработана для небольших и средних команд, которым необходимо:
- Видеть, **кто чем занят** по дням.
- Вести **задачи** с исполнителями, сроками и статусами.
- Быстро ставить **отметки** (часы / статус / комментарий).
- Учитывать **отпуска, больничные и командировки**.
- Выгружать данные в **Excel** и смотреть сводки без "Excel-ада".

💡 **Ключевое преимущество:** Работает полностью **локально** (или в корпоративной сети) на базе Flask + SQLite, используя портативный Python из папки `runtime/`. Не требует интернета или сложного DevOps-внедрения.

## ✨ Возможности

| Модуль | Что умеет |
|--------|-----------|
| **📅 Календарь** | Просмотр по дням, выставление отметок, статус «назначено, но не начато», копирование расписания вчерашнего дня. |
| **📋 Задачи** | Создание, назначение, дедлайны, приоритеты, карточка задачи с полной историей изменений. |
| **🔥 Тепловая карта** | Визуализация нагрузки сотрудников и целых отделов. |
| **📊 Свод / 📈 Статистика** | Учёт часов, покрытие задач, просрочки, аналитические срезы по людям и проектам. |
| **🏖 Отпуска** | Ручной ввод и **массовый импорт из Excel** (поддержка листов по отделам). |
| **👤 Личный кабинет** | Персональные задачи, график отсутствий, остаток нормы отпуска. |
| **🔔 Уведомления** | Иерархическая система: сотрудник → руководитель команды → начальник отдела. |
| **⚙️ Справочники** | Управление сотрудниками, отделами, командами и матрицей прав доступа. |
| **🔌 Плагины** | Расширяемость: Gantt, capacity planning, reminders, weekly report, auto-close overdue и др. |

## 🚀 Быстрый старт

### Вариант 1: Windows (Рекомендуемый)
1. Распакуйте архив или клонируйте репозиторий.
2. Запустите файл **`START.bat`** (двойным кликом).  
   *(Если требуется первоначальная установка библиотек, используйте **`START_wheels.bat`**, см. раздел ниже).*
3. Откройте в браузере: **[http://localhost:5431/](http://localhost:5431/)**

> ⚠️ **При первом запуске** автоматически создаётся учётная запись администратора. Пароль выводится в консоль сервера — **обязательно смените его** после первого входа.
